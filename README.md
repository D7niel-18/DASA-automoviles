# DASA — Fase 1: Diseño y planificación

**Proyecto:** DASA — Landing page automovilística  
**Fase:** 1 — Diseño y planificación  
**Tipo de proyecto:** Sitio web corporativo / Landing page  
**Tecnologías previstas:** HTML5, CSS y JavaScript  
**Estado:** Planificación

---

## 1. Objetivo del proyecto

El objetivo de DASA es desarrollar una landing page para una marca ficticia de automóviles, tomando como referencia visual y estructural la página web de [EBRO](https://www.ebroauto.com/).

Se busca crear una página moderna, elegante y profesional que transmita los valores de una marca automovilística: tecnología, innovación, potencia y confianza.

La web estará enfocada en presentar la marca, mostrar sus diferentes modelos de vehículos y destacar sus características principales.

El diseño deberá ser responsive, adaptándose correctamente a ordenadores, tablets y dispositivos móviles.

## 2. Identidad visual y logotipo

### 2.1. Nombre de marca

**DASA**

Se utilizará una identidad visual propia, con un logotipo sencillo, reconocible y de estética moderna.

### 2.2. Personalidad de marca

La identidad de DASA estará basada en los siguientes conceptos:

- **Modernidad:** diseño actual y minimalista.
- **Tecnología:** innovación y equipamiento avanzado.
- **Deportividad:** vehículos con personalidad y presencia.
- **Elegancia:** una estética cuidada y profesional.
- **Confianza:** transmitir seguridad y fiabilidad.

### 2.3. Logotipo

El logotipo estará formado principalmente por el nombre DASA, utilizando una tipografía geométrica, moderna y de carácter tecnológico.

Se buscará un diseño limpio, preferiblemente en blanco sobre fondos oscuros y en negro sobre fondos claros.

Se contemplarán dos versiones:

- Logotipo principal para fondos oscuros.
- Logotipo alternativo para fondos claros.

## 3. Paleta de colores

La identidad cromática estará compuesta por una combinación de tonos oscuros, blancos y un color naranja como elemento identificativo de la marca.

| Color | Código HEX | Aplicación |
|---|---|---|
| Negro carbón | #151A1E | Fondos oscuros y footer |
| Blanco cálido | #F1EFEA | Fondos de secciones |
| Naranja DASA | #FF791F | Botones y elementos destacados |
| Blanco | #FFFFFF | Textos y elementos claros |
| Gris acero | #737B83 | Textos secundarios y bordes |

### 3.1. Uso de los colores

- El negro carbón será el color principal de las secciones oscuras.
- El blanco cálido se utilizará para diferenciar secciones y aportar contraste.
- El naranja será el color corporativo y se reservará para llamadas a la acción, enlaces y detalles importantes.
- El gris acero se utilizará para textos secundarios y elementos menos destacados.

Se evitará abusar del naranja para mantener una estética equilibrada.

## 4. Tipografías

Se utilizarán dos familias tipográficas de Google Fonts.

### 4.1. Sora

**Uso:** tipografía principal.

Se utilizará en:

- Títulos y encabezados.
- Navegación.
- Botones.
- Elementos destacados.

Características: geométrica, moderna y tecnológica.

Enlace: https://fonts.google.com/specimen/Sora

### 4.2. Inter

**Uso:** tipografía secundaria.

Se utilizará en:

- Párrafos.
- Descripciones de vehículos.
- Textos informativos.
- Especificaciones técnicas.

Características: legible, versátil y adecuada para interfaces web.

Enlace: https://fonts.google.com/specimen/Inter

## 5. Diseño responsive

La página deberá adaptarse a diferentes resoluciones de pantalla, garantizando una buena experiencia de usuario independientemente del dispositivo.

Se trabajará con un enfoque *Mobile First*, comenzando por el diseño para dispositivos móviles y ampliándolo posteriormente a pantallas de mayor tamaño.

### 5.1. Resoluciones de referencia

| Dispositivo | Resolución orientativa |
|---|---|
| Móvil | 320px - 767px |
| Tablet | 768px - 1023px |
| Escritorio | 1024px - 1439px |
| Pantallas grandes | 1440px en adelante |

### 5.2. Adaptaciones necesarias

- Navegación mediante menú hamburguesa en móviles.
- Imágenes adaptadas al tamaño de pantalla.
- Tarjetas de vehículos reorganizadas en una columna en móviles.
- Textos y encabezados con tamaños adaptables.
- Botones accesibles y fáciles de pulsar.
- Secciones con espaciados adecuados para cada dispositivo.
- Evitar desplazamientos horizontales.

### 5.3. Tecnologías CSS

Se utilizarán principalmente:

- Flexbox.
- CSS Grid.
- Media Queries.
- Unidades relativas (rem, %, vw y vh).

## 6. Selección de imágenes

Las imágenes tendrán un papel fundamental en la identidad visual de DASA.

Se buscarán fotografías de alta calidad que transmitan deportividad, elegancia y tecnología.

### 6.1. Imágenes necesarias

| Sección | Imagen requerida |
|---|---|
| Hero principal | SUV en una carretera o entorno natural |
| Modelos | Fotografías individuales de cada vehículo |
| Tecnología | Interior del vehículo y salpicadero |
| Experiencia | Detalles de conducción y equipamiento |
| Footer | No requiere imagen principal |

### 6.2. Estilo fotográfico

Se priorizarán imágenes con las siguientes características:

- Fotografías realistas y de alta resolución.
- Vehículos con iluminación cinematográfica.
- Entornos naturales, carreteras y paisajes.
- Fondos oscuros o neutros.
- Composiciones limpias que permitan integrar textos.
- Coherencia visual entre todas las fotografías.

### 6.3. Recursos de imágenes

Se podrán utilizar los siguientes bancos de imágenes:

- Unsplash: https://unsplash.com/
- Pexels: https://www.pexels.com/
- Pixabay: https://pixabay.com/

Se comprobarán las condiciones de licencia y uso de cada imagen antes de incorporarla al proyecto.

## 7. Estructura visual de la landing page

La página principal estará dividida en las siguientes secciones:

1. **Header:** logotipo DASA, menú de navegación y botón de configuración.
2. **Hero:** imagen principal de un vehículo, eslogan y llamada a la acción.
3. **Modelos:** presentación de los diferentes vehículos de la marca.
4. **Tecnología:** características tecnológicas e imágenes del interior.
5. **Experiencia:** garantía, asistencia en carretera y financiación.
6. **Actualidad:** noticias y novedades de DASA (opcional).
7. **Footer:** enlaces de navegación, redes sociales e información legal.

### 7.1. Modelos ficticios de vehículos

Para la presentación inicial de la marca se plantean tres modelos:

- **DASA X3:** SUV compacto. Versátil y urbano.
- **DASA X5:** SUV familiar. Equilibrio entre espacio y comodidad.
- **DASA X7:** SUV premium. Mayor espacio y equipamiento.

Estos nombres se utilizarán como contenido ficticio del proyecto.

## 8. Resultado esperado de la fase

Al finalizar esta primera fase se deberá disponer de:

- Identidad visual definida.
- Logotipo principal y alternativo.
- Paleta de colores documentada.
- Tipografías seleccionadas.
- Diseño de referencia de la landing page.
- Planificación responsive.
- Selección inicial de fotografías.
- Estructura de las secciones de la página.
